# 首版发布前缺项

截至 2026-10-28，本地功能实现与构建已有证据，但**不能标记为可提审完成**。用户已回复：外部信息暂未准备，之后补齐。

## 由用户后续提供

1. 拟发行国家和地区。
2. 真实开发者展示主体、支持邮箱及审核联系信息。
3. 可持续访问的公开隐私政策 URL 和支持 URL。提供后补入应用内设置并检查跳转、失败说明及网页内容。
4. 账号、名称可用性、所选地区适用的许可或资质资料。
5. 正确签名团队/证书与分发配置的确认。当前未修改任何已有签名或发布设置。

应用目前有有效的离线隐私说明与 FAQ，不显示空 URL、假邮箱或失效的“联系我们”按钮。正式隐私政策还需要主体、联系渠道与生效日期，不能把当前本地说明当作完整的公开发布政策。

## 必须补做的验收

- 至少 5 人独立试玩：首次教学、误触、前三关卡点、提示使用、单局时间及后期难度。当前可解并不代表难度曲线已通过产品验收。
- 真实触摸的方向锁定、取消滑动、连续动画、后台中断、失败恢复、重开确认与导航回退。
- 真机小屏/大屏及最低 iOS 15；发布时当前稳定系统。当前只有 iOS 26.5 两种尺寸模拟器渲染覆盖。
- VoiceOver 朗读和自定义动作、最大动态字体、减弱动态效果、音效/音乐/静音/触觉、来电与音频打断。
- 飞行模式完整主线与每日挑战切换；尽管代码无网络依赖，仍需真机离线体验记录。
- 30 分钟持续游戏、内存和帧率/能耗检查。当前没有 60 fps 或长期内存稳定性测量结论。
- 最终签名 Archive、Organizer/上传验证、隐私报告核对及真正来自最终构建的 5 张商店截图。

## 商店文案修正

原 `04-release.md` 的说明与审核备注是草案。当前版本设置页包含 **offline privacy information and help**，尚无公开网页链接。不能把草案中的“support and privacy links”作为已完成功能提交。公开网址补齐后再逐句复核。

当前无账号、无广告、无内购、无第三方统计或网络请求。App Privacy 的最终填写仍需以最终签名包及未来支持网页实际行为为准。

## 官方核验入口

2026-10-28 读取了 [Apple 提交说明](https://developer.apple.com/app-store/submitting/)。该页要求准备年龄分级、隐私资料、产品页和设备验证，并列出 2027 年 4 月起采用 iOS 27 SDK 的未来要求；不要据此把本机 Xcode 26.6 的构建结果等同于发布当日上传校验。

[Required Reason API 文档](https://developer.apple.com/documentation/bundleresources/describing-use-of-required-reason-api) 是最终隐私清单复核入口。本次未使用 UserDefaults、文件时间戳、磁盘容量或系统启动时间 API；代码不猜填理由代码。

本次授权不包括提交审核、公开发布或替用户选择发行地区；均未执行。
