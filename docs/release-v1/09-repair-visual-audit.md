# 维修页整页视觉核对

2026-10-29，维修页视觉 v4。前两轮只关注玩具和可移动零件，遗漏了同页的障碍、目标预览和操作控件。本轮按页面逐项对照原型处理。

[实际页面前后对比](../../design/repair-v4/preview.html)

| 页面元素 | 本轮结果 |
| --- | --- |
| 齿轮、电池 | 沿用已校正的珊瑚红、薄荷绿 v3 美术与原生衬线等级字 |
| 障碍 | 蓝色方块和文字叉替换为深灰金属板、四角螺钉、圆形中心和凹刻 X |
| 交付格 | 原空圈替换为金色机器人标识；有零件时优先显示零件，精确匹配后边框变绿 |
| 补给入口 | 蓝色箭头圆牌；已有零件时保留蓝框而不遮挡零件 |
| 订单目标 | 复用相同零件美术，显示等级、交付计数和完成勾号；辅助功能名称包含类型、等级及进度 |
| 接下来补给 | 复用相同零件美术，保留顺序箭头、入口位置和堵塞说明；耗尽时清除预览及辅助功能旧值 |
| 底部操作 | 统一原生圆形高光、细描边和阴影；交付绿、撤销红、重开蓝、提示金，保留文字标签 |
| 页面背景 | 添加温暖木纹；说明与卡片仍为原生可读文字 |
| 规则与帮助 | 同步将旧红框交付说明改为金框，避免视觉与说明矛盾 |

新增障碍和交付素材由内置 imagegen 生成，源图在 `design/repair-v4/source`，完整提示词与来源在 `design/repair-v4/manifest.json`。使用 `python3 tools/Lirtrilner-package-repair-v4.py` 从源图重新打包。圆形操作图标由 UIKit 渐变、描边和 SF Symbols 绘制，无新依赖。

核对覆盖大小屏、中英文、两/三项目标、障碍、空交付格、零件就位、补给耗尽与零件等级。实际关卡布局及操作按钮数量以现有玩法为准，未把原型中的演示局面当作正式关卡。

后续修改视觉时，以整页同组元素为核对单位：逐项检查原型、资源引用、正常与占用状态、相关说明和大小屏结果，不能以某一张新素材或单个页面构建成功作为完成标准。

共用按钮后续修正：`LirtrilnerRaisedButton` 的渐变背景现在直接读取外层的圆角半径和曲线类型，消除普通圆弧背景与连续圆角边框之间的浅色缺口。影响首页“继续维修”及其他共用主次按钮。验证记录在 `verification/button-corners*`；此源码修正晚于 v4 历史归档。

本轮构建与渲染记录在 `verification/repair-v4`、`verification/repair-v4-iphone17pro`、`verification/repair-v4-iphone-se3`。页面渲染检查不能替代触摸、VoiceOver 或真机实测。新归档路径为 `build-artifacts/Lirtrilner-1.0-repair-v4-unsigned.xcarchive`，旧归档保留。未更改 Bundle ID、签名团队或发布配置。
