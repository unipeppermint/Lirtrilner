# 发条修理铺首版上线资料

版本：1.0 产品基线。更新日期：2026 年 10 月 29 日。工程标识：Lirtrilner。

首版目标是可提交 App Store 审核的完整免费游戏。采用玩具修理铺主题，提供局部行列滑动、零件合并、精确交付和玩具修复收藏。10 关可玩版本只作为内部开发里程碑，正式版包含 36 个主线关卡和 30 个每日挑战题库关卡。

2026-10-29 已完成贴近原型的视觉升级，详见 [视觉升级记录](08-visual-v2.md) 和 [前后页面对比](../../design/visual-v2/preview.html)。

## 已确定的产品基线

| 项目 | 首版决策 |
| --- | --- |
| 产品名 | 发条修理铺，正式名称可用性在提审前核验 |
| 收费方式 | 免费下载、全部玩法免费；本资料按无广告、无内购执行 |
| 平台 | iPhone 竖屏，iOS 15.0 起 |
| 语言 | 简体中文和英文，作为本次上线规划基线 |
| 内容 | 36 个主线关卡，12 件玩具，每件 3 个维修阶段；30 个每日挑战题目循环 |
| 核心规则 | 5×5，局部滑动，2 种零件，4 个等级，固定障碍，精确交付 |
| 技术 | Swift、UIKit、系统动画、内置 JSON、本地存档 |
| 数据 | 无账号、无业务服务器、无第三方统计或广告 SDK |
| 延后 | 闸门、自由布置、排行榜、云同步、额外主题 |

海岛与灯塔方案、付费解锁章节方案均已被替代。历史文件仍保留在原 design/prototypes 目录，不进入本次有效资料包。

## 当前交付状态

已实现 Swift + UIKit 应用、36 主线与 30 每日题库、12 件三阶段玩具、完整辅助页面、双语、存档、提示和统一的立体玩具美术。14 项 Core 测试通过，66 条参考解全部重放成功，Debug 模拟器构建与未签名 Release 归档成功。

已生成 iPhone 17 Pro 与 iPhone SE 第三代、iOS 26.5 的中英页面渲染核验。尚未完成真实触摸、VoiceOver、最低系统、真机、30 分钟性能与 5 人试玩；不把渲染核验当作这些测试。用户确认外部发布资料稍后补齐。未提交审核或公开发布。

## 使用约定

产品数值和规则以产品方案为准；原型里的文案与计数修正按交互规范执行。开发中涉及玩法、发行平台或收费方式的变更，需要同步更新这套资料，避免页面、关卡和审核说明相互矛盾。
